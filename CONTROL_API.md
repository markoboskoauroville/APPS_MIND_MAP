# Control API: how to drive each app

Apps are grouped by control level, derived from the catalog `type`, `actions` and `notes` and never upgraded beyond the evidence:

- **door**: Standard door (/health, /api, POST /api/<action>)
- **http**: Own HTTP routes
- **other**: Other protocols (OSC, MIDI, WebSocket, URL scheme)
- **cli**: Command line or script only
- **adb**: Android adb / intents
- **accessibility**: Accessibility button ids only

The standard door: listen on `127.0.0.1` at a `MANTRA_PORTS` port; `GET /health`; `GET /api` (actions with a `does` sentence each); `POST /api/<action>` with a JSON body; answers `{ok, result}` or `{ok: false, error}`. From Python: `mantra_remote.call("<app-id>", "<action>", **args)` through the Mantra Door, which launches a stopped app first. Never put a token, address or password in a call you write down; the Mantra Door token lives in a local file. Retired apps are marked (retired).
