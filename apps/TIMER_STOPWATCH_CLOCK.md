## What it can do

- Run a stopwatch (S), timer (T) or clock (R)
- Start and pause by click, reset by double click or long press
- Show full screen inside the window with only the numbers
- Set timer length and presets, count-in, colours and transparency
- Keep running state across quit and remember window place

## Ask for it when

- count time on screen
- set a countdown timer
- show a big clock
