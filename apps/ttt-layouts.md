## What it can do

- Provide one importable TTT profile with Marko's keyboard rows and key colours
- Leave the user's own prompts and API keys untouched when applied

## Ask for it when

- apply my TTT keyboard layout
- restore the TTT keys and colours on a new phone

## How to control it

No control API found.

## Inputs / Outputs

Outputs:

- TTT profile

## Works with

- Uses: [TTT Voice Type keyboard](TTT.md)

## Notes

Use: put the file in Documents/TTTmini/ then TTT › Settings › Profiles › Marko-layout › apply. TTT releases live in the TTT repo.
