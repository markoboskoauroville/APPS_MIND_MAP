## What it can do

- Provides four FlorisBoard theme stylesheets (Sunrise, Matrimandir, Banyan, Noon)
- Imports into FlorisBoard or forks using the same theme format, including Mantra Voice Type

## Ask for it when

- change the colours of my phone keyboard
- install the Auroville theme on FlorisBoard
- dark gold keyboard theme for Mantra Voice Type
