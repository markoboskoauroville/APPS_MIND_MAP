## What it can do

- Describes a master plus child-agent working pattern with fixed brief and ten-line reports
- Provides templates: master CLAUDE.md, child brief, SKILL.md, router idea
- Explains cache discipline and model/effort choice to save tokens

## Ask for it when

- how should I split work across Claude Code subagents
- template for briefing a child agent
- save tokens in Claude Code
- route tasks to Haiku, Sonnet or Opus
